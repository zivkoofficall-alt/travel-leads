# Waylen Travel — лендинг «Путешествия с животными»

Стек: **статический HTML** (без сборки) + **Supabase** (база заявок, уже создана и настроена) +
**Vercel Serverless Function** (только уведомление в Telegram) + **Яндекс.Метрика**.

## Supabase уже настроен

Проект **waylen-travel** создан, таблица `leads` и политика доступа применены напрямую через
подключённую интеграцию — вам не нужно ничего создавать в Supabase самостоятельно.

- URL проекта и публичный (анонимный) ключ уже встроены прямо в `index.html`.
- Этот ключ **безопасно** видно всем в исходном коде сайта — у него по политике безопасности
  есть только право **добавлять** новые заявки. Читать, менять или удалять чужие заявки
  через него невозможно.
- Посмотреть все заявки можно в самом Supabase → Table Editor → таблица `leads`
  (зайдите под своим аккаунтом people circle → проект waylen-travel).

Файл `supabase-schema.sql` в архиве — просто справочная копия того, что уже применено,
на случай, если понадобится пересоздать таблицу в другом проекте.

## Что нужно сделать вам: GitHub → Vercel → Telegram

### 1. GitHub
Создайте репозиторий на github.com, загрузите туда все файлы из этой папки
(«Add file → Upload files» — можно перетащить всю папку).

### 2. Telegram — узнать chat_id
Токен бота у вас уже есть. Напишите боту `/start`, затем откройте в браузере:
```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```
В ответе найдите `"chat":{"id": ...}` — это `TELEGRAM_CHAT_ID`.
Для группового чата — добавьте бота в группу, напишите что-нибудь, найдите так же (id будет отрицательным).

### 3. Vercel
1. vercel.com → **Add New → Project → Import Git Repository** → выберите репозиторий.
2. На экране импорта добавьте 2 переменные окружения:

   | Имя | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | ваш токен бота |
   | `TELEGRAM_CHAT_ID` | из шага 2 |

3. **Deploy**. Через минуту сайт будет жить на ссылке вида `your-project.vercel.app`.

Больше никаких переменных не нужно — Supabase уже полностью настроен.

### 4. Яндекс.Метрика (по желанию)
Зарегистрируйте счётчик на metrika.yandex.ru. В `index.html` найдите две строки с числом
`00000000` (`ym(00000000, "init"...` и `src=".../watch/00000000"`) и замените на номер счётчика.
Залейте обновлённый файл в GitHub — Vercel передеплоит сайт сам.
В настройках счётчика включите **Вебвизор** и **Карту кликов** — это и есть тепловая карта.

## Проверка, что всё работает

1. Откройте задеплоенный сайт, заполните форму внизу, отправьте.
2. Заявка должна появиться в Supabase → Table Editor → `leads` почти сразу.
3. Уведомление должно прилететь в Telegram почти сразу.
4. Если форма показывает ошибку — проверьте `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` в Vercel
   и сделайте **Redeploy** (Deployments → ⋯ → Redeploy) — переменные подхватываются только
   при новом деплое. Сама заявка в Supabase сохранится даже если уведомление в Telegram не дойдёт —
   это два независимых шага, второй никогда не блокирует первый.
